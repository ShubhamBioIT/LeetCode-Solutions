# 🎨 HTML Web Designing Project

A modern, responsive, and beautiful web design project showcasing HTML, CSS, and JavaScript skills.

## 📋 Project Overview

This is a complete web design project featuring a multi-section website with modern design principles, smooth animations, and responsive layouts that work seamlessly across all devices.

## ✨ Features

### Design Features
- 🎨 **Modern UI/UX** - Clean and professional design with gradient effects
- 📱 **Fully Responsive** - Works perfectly on desktop, tablet, and mobile devices
- ⚡ **Smooth Animations** - Engaging scroll animations and transitions
- 🎯 **Intuitive Navigation** - Easy-to-use navigation with smooth scrolling
- 🌈 **Gradient Color Scheme** - Eye-catching purple-blue gradient theme

### Technical Features
- ✅ **Pure HTML5** - Semantic HTML structure
- ✅ **Modern CSS3** - Flexbox, Grid, Custom Properties, and Animations
- ✅ **Vanilla JavaScript** - No dependencies, pure ES6+ JavaScript
- ✅ **Mobile-First Design** - Optimized for mobile devices
- ✅ **Accessible** - Following web accessibility best practices
- ✅ **SEO Friendly** - Proper meta tags and semantic structure

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, Edge)
- A text editor (VS Code, Sublime Text, Atom, etc.) - for editing
- Basic understanding of HTML, CSS, and JavaScript

### Installation

1. **Clone or Download** the repository
   ```bash
   git clone https://github.com/ShubhamBioIT/LeetCode-Solutions.git
   cd LeetCode-Solutions/HTML-Web-Designing-Project
   ```

2. **Open the Project**
   - Simply open `index.html` in your web browser
   - Or use a local server for better development experience:
     ```bash
     # Using Python
     python -m http.server 8000
     
     # Using Node.js
     npx http-server
     ```

3. **Start Editing**
   - Edit HTML in `index.html`
   - Modify styles in `css/style.css`
   - Add functionality in `js/script.js`

## 🎨 Customization Guide

### Colors
Edit the CSS variables in `css/style.css`:
```css
:root {
    --primary-color: #667eea;
    --secondary-color: #764ba2;
    --text-color: #333;
    --light-bg: #f7fafc;
    --white: #ffffff;
}
```

### Content
- Update text content in `index.html`
- Replace placeholder images in the `images/` folder
- Modify section content as needed

### Styling
- All styles are in `css/style.css`
- Organized by sections for easy navigation
- Includes responsive breakpoints at 768px and 480px

### Functionality
- JavaScript features in `js/script.js`
- Includes smooth scrolling, form validation, and animations
- Easy to extend with additional features
