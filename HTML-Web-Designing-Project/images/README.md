# Image Assets

Place your image files in this directory.

## Recommended Images

- Logo (logo.png or logo.svg)
- Portfolio project screenshots
- Team member photos
- Background images
- Icons and graphics

## Image Optimization Tips

1. Use appropriate formats (JPEG for photos, PNG for graphics with transparency, SVG for logos)
2. Compress images before uploading
3. Use descriptive filenames
4. Consider using WebP format for better compression
5. Provide alt text for all images

## Recommended Tools

- TinyPNG/TinyJPG - https://tinypng.com/
- Squoosh - https://squoosh.app/
- ImageOptim - https://imageoptim.com/
